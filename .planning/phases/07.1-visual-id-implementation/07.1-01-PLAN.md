**Primary path — Google Fonts pre-subset latin woff2** (the "latin" subset spans U+0000–00FF, which includes every pt-BR diacritic: ç ã õ é ê í ó ú à â; plus U+2013–2014 em/en dash used in "Hellz — Painel Geral"):

1. Fetch the css2 stylesheet with a woff2-capable User-Agent (PowerShell):
```powershell
$resp = Invoke-WebRequest -Uri "https://fonts.googleapis.com/css2?family=Orbitron:wght@600;700;900&display=swap" -Headers @{ "User-Agent" = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/125.0 Safari/537.36" } -UseBasicParsing
$resp.Content | Set-Content "$env:TEMP\orbitron.css"
```
2. From the CSS content, for EACH weight (600, 700, 900) take the woff2 URL inside the `@font-face` block whose comment marker is `/* latin */` (NOT `latin-ext`) and download it to `public/fonts/orbitron-latin-{weight}.woff2`.
3. Verify each file: (a) exists and is 8–60 KB; (b) first 4 bytes are ASCII `wOF2` (check via `[System.Text.Encoding]::ASCII.GetString((Get-Content file -Encoding Byte -TotalCount 4))` or node `Buffer.readUInt32BE`); (c) NOT an HTML error page.

**Fallback path (only if fonts.googleapis.com is unreachable)** — pyftsubset with the environment's Python 3.14:
```powershell
pip install fonttools brotli
Invoke-WebRequest -Uri "https://github.com/google/fonts/raw/main/ofl/orbitron/Orbitron%5Bwght%5D.ttf" -OutFile "$env:TEMP\Orbitron-VF.ttf"
fonttools varLib.instancer "$env:TEMP\Orbitron-VF.ttf" wght=600 -o "$env:TEMP\Orbitron-600.ttf"   # repeat for 700, 900
pyftsubset "$env:TEMP\Orbitron-600.ttf" --output-file="public/fonts/orbitron-latin-600.woff2" --flavor=woff2 --layout-features="kern,liga" --unicodes="U+0020-007E,U+00A0-00FF,U+2013,U+2014,U+2018,U+2019,U+201C,U+201D,U+2026"   # repeat per weight
```

Do NOT add any npm dependency or build step — the committed woff2 IS the subset (research: dont_hand_roll).

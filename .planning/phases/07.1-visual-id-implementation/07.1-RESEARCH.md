## Summary

This phase is a **token-layer rewrite plus targeted component styling** — no new subsystems. The entire live hex surface of the app is `src/index.css` `@theme` (grep confirmed: 15 hexes, all in `@theme`) except ONE hardcoded `accent-[#E3B341]` in `src/features/submit/SubmitPage.tsx:94` and a code comment in `FocusStrip.tsx:10`. Swapping token values propagates automatically through every `bg-dominant` / `border-line` / `text-accent` / `ring-accent` utility. New capabilities needed: custom glow utilities (`@utility`), a grid backdrop (component class), a display font (`--font-display` theme key + `@font-face`), and a favicon.

## standard_stack

- **Tailwind v4.3.3 (already in repo)** — CSS-first config; verified capabilities used by this phase:
  - `@theme { --font-display: "Orbitron", ...; }` → generates the `font-display` utility.
  - `@utility <name> { ... }` → registers custom utilities (works with variants like `hover:`). Verified in official docs.
  - `@layer base { h1 { font-family: var(--font-display); } }` → base-layer element default (official docs pattern).
  - Tailwind v4 ships a `text-shadow` utility namespace; for the glow treatment we use custom `@utility` rules for full control of radii/colors.
- **Display font: Orbitron** (Google Fonts, SIL OFL 1.1 — license-safe, committable). Geometric/technical sci-fi letterforms; digits read sharply at hero sizes. Latin subset covers U+0000–00FF, which includes every pt-BR diacritic (ã õ ç é ê í ó ú à â). Weights used: 600/700/900.
- **Font subsetting:** primary path — self-host Google's pre-subset **latin woff2** (it IS a subset; ~15–25 KB per weight; no build tooling added to the repo). Fallback path — `pyftsubset` via the environment's Python 3.14 (`pip install fonttools brotli; pyftsubset Orbitron-*.ttf --unicodes=... --flavor=woff2`).
- **Favicon:** plain SVG file at `public/favicon.svg`, referenced by the existing `<link rel="icon" type="image/svg+xml">` in `index.html` (already points there — the current file is the default Vite logo).

## architecture_patterns

1. **Token swap, not utility hunt.** Every page consumes tokens (`bg-dominant`, `border-line`, `text-muted`, `ring-accent`, `bg-accent`, tier classes from `presentation.ts` literal maps). Changing `@theme` values restyles the whole panel with zero component churn.
2. **Literal Tailwind class maps stay.** `src/features/dashboard/presentation.ts` exports `TIER_BORDER/TIER_TEXT/TIER_BG` as literal strings (v4 JIT requirement). Tier classes don't change — only the hex values behind `--color-tier-*`.
3. **Custom utilities are CSS-first** (`@utility` in `src/index.css`), same home as `@theme` — no tailwind.config, no plugins.
4. **Logo asset strategy:** copy (never move) `h-logo/hellz.svg` → `src/assets/hellz-mark.svg` for `<img src>` imports (Vite resolves URL imports) and → `public/favicon.svg` for the favicon. The mark's 4 flat fills (`#1a1a1a` plate, `#660000` shadow, `#b70302`/`#b3080a` red strokes) read on dark surfaces as-is — the dark plate disappears into dark chrome and the red strokes carry the silhouette. No recolor needed unless visual verification says otherwise (owner discretion item).
5. **Static-only neon (D-05):** all glows are static `box-shadow`/`text-shadow`. Any transition added is hover/focus-only and wrapped in a `prefers-reduced-motion` guard.
6. **Backdrop discipline (D-04):** grid/gradient backdrop utility applied ONLY on LoginPage root and HighlightsPage root. Data-dense pages (Painel, Enviar, staff pages) get nothing.

## common_pitfalls

- **P1 — `font-display` name collision:** Tailwind ALSO has a `font-display` CSS property concern; the `--font-display` theme key generating a `font-display` utility is standard v4 (docs use exactly `--font-display` in their example), but to avoid reader confusion use font-family name `"Orbitron"` and token `--font-display` (docs-canonical).
- **P2 — Favicon caching:** browsers cache favicon.svg aggressively; during visual verification use a hard refresh / incognito.
- **P3 — Stale gold references:** `SubmitPage.tsx:94` `accent-[#E3B341]` and the `FocusStrip.tsx:10` comment mention legacy gold — both must be updated or the grep gate fails.
- **P4 — `--color-accent-foreground` on red:** dark-on-red fails nothing, but white-on-`#B70302` is 6.9:1 while white-on-brightened-red can dip below 4.5 — keep button fill and foreground pairing from the ramp table below (verified pairs only).
- **P5 — Orbitron is NOT a body font (D-07):** never apply `font-display` to body/labels/forms/inputs; only wordmark, h1s, and hero numbers (OVR / top-3 points).
- **P6 — Animated glow regression:** no `animation`/`keyframes` anywhere in this phase; transitions only on `hover`/`focus-visible` and motion-safe-guarded.

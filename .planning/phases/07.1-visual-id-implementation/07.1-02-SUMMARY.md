## Decisions Made

- **tierDisplay.ts as a separate render-layer module** (owner decision at gate round 3): the top band — internally still `platinum` in presentation.ts — displays as "Impecável" with rainbow treatment. presentation.ts band logic, literal maps, and its test suite stay byte-for-byte untouched (VIS-07 zero-behavior-change)
- **Destaques shows only Impecável-tier players** (owner decision, fix 4.2) — the promotion page becomes an exclusive showcase
- **Hover transitions allowed** (owner-directed, fix 7): the plan-level "no transitions" guard targeted *autonomous* animation per D-05; user-initiated hover feedback was explicitly permitted at the gate. The static-only rule for self-running motion still holds (zero keyframes in src)
- **Personagens restructured as cards** (fix 6): the owner rejected the initial `-mx-2` negative-margin approach; controls moved below each character card, replacing the table layout
- **SVG consumed only via `<img src>`** with Vite URL imports (per plan T-07.1-05 mitigation) — never inlined into JSX

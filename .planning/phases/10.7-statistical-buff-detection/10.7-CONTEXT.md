# Phase 10.7 — Statistical Buff Detection (CONTEXT)

**Owner request (2026-10-30):** "instead of just considering the 1.5x margin, lets use the data we already have to catch possible cheaters. another buff that is frequently used to cheat is impositio manus, which gives +35% PATK and MATK by raising its equipament ATK% stat. We can calculate the flat stats and try to stabilish a curve, and look for deviations of the curve."

## The signal

Within one stats cohort (class group + build-role), the **normalized base** is far tighter than the raw percent stat:

```
base = flat / (1 + pct/100)
```

Live example — Biochemist/suporte PATK: `pct` ranged 20.96–35.04 while `base` stayed 2.830–3.523. A buff that raises both the flat ATK and the Equipment ATK% therefore moves the pair along the curve, and the base residual exposes it. The buff's +35% / +35 p.p. signature can also be reversed (`flat/1.35`, `pct-35`) and tested against the curve.

## Locked decisions

| # | Decision |
|---|----------|
| D-10.7-01 | Curve = proportional model `flat = base * (1 + pct/100)`. Cohort baseline = **median** of base (not mean) + **MAD** scale, latest validated, self excluded, `n ≥ 5`. Scale floor = max(1.4826×MAD, 5% of median, 1); pct scale floor = 5 percentage points. |
| D-10.7-02 | Impositio Manus test: `z_pct ≥ 2.0`, `z_base ≥ 1.0`, the de-buffed base (`flat/1.35`, `pct-35`) is within 1.5σ of the cohort median, and it fits better than the observed base (`z_debuff < z_base - 0.5`). |
| D-10.7-03 | General curve flag: `|z_base| ≥ 3.5` OR the actual flat deviates ≥ 30% from the curve's expected flat for that pct. |
| D-10.7-04 | Defense spikes keep the 1.5× ratio AND add a robust `z ≥ 3.5` (n ≥ 5) path; each spike carries `median`, `mad`, `z`, `reason` (`ratio` / `sigma` / `both`). |
| D-10.7-05 | The cross-cohort inspector gains `class_median`, `class_mad`, `class_z`, `class_sigma_outlier` for every stat. Sigma requires n ≥ 5 with a positive median/MAD; direction-aware (higher ≥ +3.5σ, lower ≤ -3.5σ). The fixed 1.5× badges remain as fallbacks/context. |
| D-10.7-06 | Review aid only — nothing is auto-rejected. Cohorts below n=5 get `available:false` / null sigma and rely on the 1.5× rule. The robust median/MAD resists one contaminated value; the mean-based 1.5× remains the simple safety net. |
| D-10.7-07 | Impositio constants are the owner-stated +35% flat and +35 percentage points. A lower-level buff may not fit the undo test as cleanly; the pct sigma + curve still catch it. |
| D-10.7-08 | **Curve-only refinement (owner, 2026-10-30: "vamos descartar o padrão, e usar apenas a curva como referencia").** The fixed 1.5× margin and the guild-wide "Fora do padrão" shorthand are removed from the reference logic. Defense flags and the player warning use only the robust median/MAD sigma (n ≥ 5); the Ranking stat mode drops the ratio columns and both fixed-threshold badges. Legacy average/ratio fields stay in the payload for cached bundles but never flag. Cohorts below n=5 now produce no automatic curve signal. |

## Why not a regression line

With 3–10 members per cohort, OLS is unstable and one outlier tilts the fit. The normalized-base model is the same curve in closed form, with a robust center and scale. It is explainable to officers: "base 3.595 (1,2σ) vs median 3.354; removing +35%/+35 p.p. gives 3.354 (0,2σ)".

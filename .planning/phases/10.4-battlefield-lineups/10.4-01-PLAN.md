1. **Tables & Constraints (`LNUP-01`, `LNUP-03`):**

     - `battlefield text not null check (battlefield in ('vigrid_field', 'ruinscape'))`
     - `party_index smallint not null check (party_index between 1 and 8)`
     - `role_label text null check (role_label is null or char_length(trim(role_label)) <= 40)`
     - `updated_at timestamptz not null default now()`
     - `primary key (battlefield, party_index)`
   - `public.lineup_slots`:
     - `battlefield text not null`
     - `party_index smallint not null`
     - `slot_index smallint not null check (slot_index between 1 and 5)`
     - `member_id uuid null references public.members(id) on delete set null`
     - `updated_at timestamptz not null default now()`
     - `primary key (battlefield, party_index, slot_index)`
     - `foreign key (battlefield, party_index) references public.lineup_parties(battlefield, party_index) on delete cascade`
     - `constraint lineup_slots_unique_member unique (member_id)` (a player can occupy at most 1 slot across both raids; `NULL` values do not conflict in Postgres `UNIQUE`).

2. **RLS & Privilege Hygiene (`LNUP-02`):**
   - Enable RLS on `lineup_parties` and `lineup_slots`.
   - `revoke all on public.lineup_parties, public.lineup_slots from anon, authenticated;`
   - `grant select on public.lineup_parties, public.lineup_slots to authenticated;`
   - Policy `active_member_select_lineup_parties` and `active_member_select_lineup_slots`: `for select to authenticated using (exists (select 1 from public.members m where m.id::text = auth.jwt()->>'member_id' and m.active));`

5. **RPCs (`LNUP-01`, `LNUP-02`, `LNUP-03`):**
   - `public.get_lineups() returns jsonb` (`SECURITY DEFINER`, `stable`):
     - Gate: caller must be an active member (`auth.jwt()->>'member_id'`).
     - Coalesces each member's display nickname and class with their newest `member_identity_history` snapshot (matching `staff_members` / `role_rank` 0014 precedent: `coalesce(latest_id.nickname, m.display_name)` and `coalesce(latest_id.char_class, m.char_class)`).
     - Returns `{ battlefields: [...], roster: [...] }` where `roster` lists all active non-smoke members (`m.active and m.discord_handle not ilike 'smoke%' and m.discord_handle not ilike 'dummy-%'`) with closed fields `{ member_id, display_name, char_class, char_function }`.
   - `public.set_lineup_slot(p_battlefield text, p_party smallint, p_slot smallint, p_member uuid default null) returns jsonb` (`SECURITY DEFINER`, `volatile`):
     - Gate: active `officer` or `owner` + `perform public.assert_device_bound();`.
     - Validates `p_battlefield in ('vigrid_field', 'ruinscape')`, `p_party between 1 and 8`, `p_slot between 1 and 5`.

     - Normalizes `nullif(trim(p_label), '')`, checks length <= 40, updates `lineup_parties.role_label`, and returns `public.get_lineups()`.

<objective>
Bind the 7-day session JWT to a device fingerprint (User-Agent + IP) so that session hijacking from a foreign device is invalidated. Priority (c) per D-03 — after purge and handle rotation.

Purpose: D-13 identifies the biggest hijack risk: someone obtains a foreign screenshot of an officer's basic screen and uses it to claim a handle before the legitimate owner. Device fingerprint binding means even a stolen JWT is useless from a different device — session invalidated on binding mismatch, requires re-login.

Output: verify-pin binds device_fp to JWT; client sends X-Device-Fingerprint on every request; mismatch → 401 → clear session → re-login; smoke probe proves the boundary.
</objective>

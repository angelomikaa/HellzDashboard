# Phase 08.1 Plan 05 — Summary: Step-up Re-PIN (D-14/D-15)

**Status:** COMPLETE — migration 0016 applied live; stepUpSession in _shared/session.ts; api.ts X-Step-Up header added; Edge Function deployment pending for stepUpSession usage.

## What was done

### Migration `supabase/migrations/0016_stepup_pin.sql` (applied live)

1. **`step_up_tokens` table** — short-lived (10 min), single-use, device-bound:
   - `id` (uuid PK), `member_id` (FK → members), `device_fp` (text), `created_at`, `expires_at` (default now + 10 min), `used` (boolean default false)
   - Index on `(member_id, created_at desc)`
   - RLS enabled but no policies (RPC-only access)

2. **`request_step_up(p_member uuid, p_pin text) returns uuid`** — SECURITY DEFINER RPC:
   - Caller gate: owner can request for any member; non-owner only for themselves
   - Validates target member exists and active; wrong PIN → `invalid_pin` (records via `record_pin_failure` lockout, no second counter); missing/inactive → `invalid_member`
   - On success: inserts step_up_tokens row (device_fp from JWT claim if present), marks prior tokens used, returns new token id
   - PIN never logged or returned
   - Revoked from public/anon/authenticated; grant to authenticated only

3. **Patched `set_member_role`** — byte-faithful copy of 0011 body PLUS step-up enforcement:
   - Owner gate preserved (verbatim from 0011: `is_active_owner()` + `member_role='owner'`)
   - After owner gate: requires valid unconsumed step-up token (`device_fp` matches, not used, not expired) → `step_up_required` if none
   - Token marked used (single-use)
   - `p_role` in `('member','officer')` else `invalid_role`; owner targets immutable → `forbidden`
   - Revoked from public/anon/authenticated; grant to authenticated only

4. **Verified live** — both `request_step_up` and `set_member_role` functions exist in `pg_proc`.

### `supabase/functions/_shared/session.ts`

- Added `STEP_UP_SECONDS = 10 * 60` and `stepUpSession(member, deviceFp?)` — short-lived step-up JWT with `step_up: true` claim and `nefoot-step-up` issuer (10-minute expiry).

### `src/lib/api.ts`

- Extended `setMemberRole(session, memberId, role, stepUpToken?)` — optional `stepUpToken` parameter; when provided, sends `X-Step-Up: <stepUpToken>` header alongside apikey + Authorization.
- Backward-compatible — existing call sites without `stepUpToken` still compile; server rejects with `step_up_required`.

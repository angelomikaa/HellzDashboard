Require step-up (re-PIN) authentication before any role change / hierarchy system action, with owner-only hierarchy power. D-14/D-15 — the identification system's privileged-action safeguard.

Purpose: D-13's hijack risk — an attacker with a foreign officer screenshot must not be able to change roles. Even with a stolen session, the step-up re-PIN forces re-entry of the owner's PIN before hierarchy actions. Only the owner can perform hierarchy actions (D-15); officers cannot step-up into role changes.

Output: step_up_sessions table live; set_member_role requires verified step-up; verify-pin can mint a step-up session; CharactersPage prompts for PIN before role changes; smoke probe confirms the boundary.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → verify-pin (step_up) | Owner re-enters PIN to prove identity before hierarchy action |
| client → set_member_role | RPC requires valid step-up session; owner-only gate |
| step_up_sessions table | Short-lived, single-use; RLS enabled, no policies, RPC-only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-081-13 | Elevation of Privilege | Role change without step-up | mitigate | set_member_role requires valid step-up session; officer cannot step-up for role_change (D-15) |
| T-081-14 | Spoofing | Stolen session used for hierarchy action | mitigate | Step-up re-PIN proves PIN knowledge at this device; step-up is single-use and short-lived |
| T-081-15 | Repudiation | Role change performed but owner denies | mitigate | Step-up session records member_id + action_type + timestamp; consumed on use (audit trail) |
| T-081-16 | Denial of Service | Step-up session exhaustion | mitigate | 15-minute expiry auto-clears; single-use prevents replay; no DoS vector beyond normal lockout |
</threat_model>

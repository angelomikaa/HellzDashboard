# Phase 08.1: Smoke-harness credential hygiene + repo credential gate

**Every smoke script derives credentials from the environment or generates per-run fixtures; a random 4-digit fixture PIN replaces the shared `1234`; and `scripts/check-credentials.mjs` fails the build if a bcrypt hash, PIN literal, or live handle returns to `scripts/` or the whitelist seed.**

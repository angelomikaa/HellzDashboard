# Phase 10.6 Plan 01 — Cross-Cohort Stat Inspector

**Requirements:** XSTAT-01, XSTAT-02, XSTAT-03
**Depends on:** Phase 10.5 (`class+role` baseline conventions), Phase 10.1 (no rating formula change), Phase 07.2 (staff Ranking tab)
**Migration:** `0047_cross_cohort_stat_overview.sql`

## Goal

Officers can pick any stat in the Ranking tab and see every real member's latest validated value in one table, independent of class/cohort, with the class+role average and the guild average beside it — so a suspicious outlier is visible without opening member after member.

## Tasks

1. **Migration 0047**
   - `idx_submission_stats_stat_key` (EAV lookup by stat).
   - `stat_overview(p_stat_key text)` SECURITY DEFINER, staff gate inside, `unknown_stat` guard.
   - Latest **validated** value per member for the selected stat; fixtures (`smoke%` / `dummy-%`) excluded.
   - One row per active real member (left join; no-value rows last), with `value`, `submitted_at`, self-excluded class+role average/sample, `cohort_ratio`, `guild_ratio`, `cohort_outlier`, `guild_outlier`.
   - Guild aggregates: sample size, average, median, max, min.
   - Grants (authenticated only), comment, bookkeeping, `notify pgrst`.

2. **Client API**
   - `StatOverviewRow` / `StatOverview` types; `fetchStatOverview(session, statKey)` with a malformed-shape guard.

3. **Ranking tab**
   - Mode switch: "OVR por função" (unchanged) / "Stat entre todos".
   - Stat selector (all catalog stats grouped Geral → Quasi → Especial).
   - Guild summary line + a note explaining validated-only / fixtures / badge meaning.
   - Table: icon, name (+ID), class, function, value, class+role average `(n=)`, `vs. classe`, `vs. guilda`, last submission; red gold badges per the heuristic.
   - "Maior primeiro / Menor primeiro" ordering; `orderStatRows` is a pure view aid (`desc` returns the server array verbatim).
   - Existing OVR fetch is skipped while the stat mode is active; both fetches keep the cancelled stale-guard.

4. **Tests + gates**
   - `rankView.test.ts`: server-order verbatim, asc reverse with nulls last, pt-BR name tie-break.
   - `statOverviewMigration.test.ts`: staff gate, validated-only, fixture exclusion, self-excluded baseline, 1.5×/0.5× hints, roster left join, bookkeeping.
   - Full suite, `tsc -b`, `oxlint`, `vite build`.

## Success criteria

1. Selecting `rpdef` (or any catalog stat) returns every active real member with the latest validated value and the correct baselines; members without data show `—` and sort last.
2. The red "Acima da coorte" badge uses the same 1.5× self-excluded class+role rule as the 0046 anti-cheat flag; the gold "Fora do padrão" badge is the guild-wide heuristic.
3. A member JWT receives `forbidden`; anon has no EXECUTE.
4. The OVR boards are unchanged; the new mode is additive and staff-only.
5. No new dependencies; no key-stat config in the payload.

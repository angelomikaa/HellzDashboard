## What shipped

### Server (authored, pending live apply)

`supabase/migrations/0074_stat_progress_trackers.sql`

- `public.my_stat_progress(p_stat_keys text[]) returns jsonb`
  - `SECURITY DEFINER`, internal active-member gate (`no_member_claim` /
    `forbidden`), `revoke` public/anon, `grant execute` authenticated.
  - Per requested catalog stat: `own_value`, `history` (last 3 submissions,
    newest first, `status not in ('rejected','discarded')`), and three DISTINCT
    references — `class_average` (same merged class, any role),
    `function_average` (same role, any class), `cohort_average` (class + role) —
    each with its sample size and the `n >= 3` gate.
  - Latest-value basis identical to `my_report`, so `own_value` and the newest
    history point always agree with the card.
  - Bookkeeping row + `notify pgrst`. Registered in `manifest.json`.

**Apply (owner token required):**

```
node scripts/apply-seed.mjs supabase/migrations/0074_stat_progress_trackers.sql
```

### Client

- `src/lib/api.ts`: `StatProgressPoint`, `StatProgressRow`, `MyStatProgress`,
  `fetchMyStatProgress` (closed field list + malformed-body guard).
- `src/features/dashboard/statProgress.ts`: `evidenceStatKeys`,
  `buildProgressEvidence`, `historySeries`, `chartDomain`, `signedDelta`,
  `formatHistoryDate` — pure, unit-locked.
- `src/features/dashboard/StatTrendChart.tsx`: dependency-free SVG sparkline
  (tiles) and detail plot (own history + 3 reference lines).
- `src/features/dashboard/statTrendDisplay.ts`: the four chart colors.
- `MiniStatTile`: 3-point sparkline, hover/focus popover with the last three
  values + dates, and the tile is now the progression button.
- `KeyStatCard` / `FocusStrip`: pass history + `onOpen`; FocusStrip receives the
  already-computed foco list (single source with the modal).
- `ProgressDetailModal`: accessible dialog (focus trap, Escape, backdrop, focus
  return) with one section per evidenced stat — chart, three reference rows
  with signed deltas + sample sizes, and "Ver no painel".
- `DashboardPage`: one progress fetch per `my_card` payload (degrades to null on
  failure), computes `focus` once, renders the modal.

# Phase 10.10 Plan 01 — Início Non-Platinum Fallback

**Requirements:** SHWC-02
**Depends on:** Phase 10 (Início showcase), Phase 07.1 (Impecável gate), Phase 10.2 (per-build carousels), Phase 10.3 (meta cohorts + primers)
**Migration:** none (client-only)

## Goal

Every meta build with data gets a carousel on Início. The Impecável gate keeps its
premium meaning where it can: a build shows its platinum cards; a build with no
platinum at all shows the server-ranked top 3 instead of disappearing.

## Tasks

1. **Pure selection helper** — `src/features/highlights/buildGroups.ts`
   - `selectShowcaseCards(cards)`: compute the set of functions that have at least
     one platinum card (`tierForOvr(Math.round(ovr)) === 'platinum'`), then keep a
     card when it is platinum OR its function has no platinum.
   - Preserve server order, return a new array, never mutate.

2. **Showcase wiring** — `src/features/highlights/PromotionShowcase.tsx`
   - Replace the class-wide platinum filter with `selectShowcaseCards(section.cards)`.
   - Keep the "no cards at all" empty state and the per-build token/carousel logic.

3. **Tests** — `src/features/highlights/buildGroups.test.ts`
   - Platinum build keeps only platinum cards.
   - All-non-platinum build (the OVR-83 primers) keeps all three cards.
   - Mixed class: platinum mdps + gold suporte keeps the mdps platinum and the whole suporte.
   - Order preserved; empty input returns empty.

## Success criteria

1. A meta build whose cards are all below 85 renders its carousel (top 3), not nothing.
2. A meta build with platinum cards still renders only platinum cards.
3. Selecting per build never lets one build's tier hide a sibling build.
4. Server order is preserved; no rank math in the client.
5. `tsc -b`, the full Vitest suite and `vite build` stay green; no server change.

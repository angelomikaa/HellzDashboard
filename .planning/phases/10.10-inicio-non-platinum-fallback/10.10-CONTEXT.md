# Phase 10.10 — Início Non-Platinum Fallback (CONTEXT)

**Inserted:** 2026-11-01 (owner request, client-only)
**Scope:** the public/member Início showcase (`PromotionShowcase`) only — no RPC, migration or ranking change.

## Owner request

> "incluir os não platinas, caso não hajam platinas habilitados na categoria"

Context: the showcase only renders OVR ≥ 85 (Impecável/platinum) cards. Five empty
meta builds whose primers sit at OVR 83 (guild-floor derived: Biochemist/dps,
Champion/dps, High Wizard/suporte, Stalker/dps, Summoner/suporte) therefore had their
whole carousel dropped, and a build with a single platinum card could render alone.

## Decisions

| Decision | Choice |
|---|---|
| Granularity | **Per build** (`class_name` + `char_function`), never per class |
| Rule | If the build has at least one platinum card, show only its platinum cards; otherwise fall back to the server-ranked top 3 |
| Mixed builds | A platinum build never suppresses a non-platinum sibling in the same class |
| Order | Server order preserved; no re-sort, no client rank math |
| Data | No re-seed required — the server already returns the top 3 per meta cohort |

## Constraints

- Display-only change; `tierForOvr` (07.1-02) remains the single banding function.
- No new dependency, no server/migration change, no key-stat config exposure.
- Placeholders remain non-competitive: the fallback shows the server's top 3, it never promotes a card above a real player.

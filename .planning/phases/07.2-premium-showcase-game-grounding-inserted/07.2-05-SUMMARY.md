## Decisions Made

- **Shield → tier crest SVGs → single card.svg (rounds 1-5):** each superseding owner design fully replaced the previous (shieldFrame.ts and the four crest SVGs deleted); the surviving lessons (aspect gate, fonts.ready await, scalePath mapping, stat-grid gutters) carried forward into the final design.
- **Border ON the plate silhouette (round 8):** the owner ruled the render wrong; root cause PROVEN — the file strokes the plate silhouette (cls-3 d == base-plate d, clipped to clip-path-1), while both surfaces had stroked the crop path. Parser rebuilt on the file's semantics; a permanent file-vs-app render diff (0 differing pixels on all 4 tiers on-page, ≤0.07% canvas from photo-resample AA) now guards design fidelity.
- **Bebas Neue / Orbitron split (round 7):** the owner re-seeded card.svg in Bebas and rejected the round-5 all-Orbitron swap; final split — Bebas everywhere except the player name (Orbitron), with Google Fonts degrade-to-Orbitron offline.
- **Measured fit contract (round 6):** overflow root-caused in the headless harness (0.62em advance estimate vs real ~0.834em Orbitron advances); ONE shared fit contract for both surfaces — shrink font proportionally to a 0.55 floor, emergency glyph-squeeze only past it.
- **PNG transparent export (round 7):** replaced JPEG; nothing paints outside the plate silhouette, corner alpha 0 verified.
- **Rating unification (round 8):** get_promotion's function-only cohort join (0010) deflated OVR vs my_card's class+function cohort (0013); get_promotion now delegates to the my_card basis — same value can never rank differently across surfaces.
- **Live-apply via apply-seed.mjs throughout:** bucket RLS, label remap, photo_path, and rating unification all applied to the LIVE database (token probe 200 → apply → body/policy verification); token value held in session env only, never stored or committed.

The plan's task 4 checkpoint ran 8 fix/re-present rounds, each a superseding owner design or root-caused fix (all committed, all documented in STATE.md round records). Categorized:

### Auto-fixed Issues

**1. [Rule 1 - Bug] On-page card text overflow (round 6)**
- **Found during:** task 4 (owner: "the card is overflowing… letters were not reduced")
- **Issue:** the on-page SVG squeezed textLength with a 0.62em advance ESTIMATE while real Orbitron 700 advances are ~0.834em — a 2-digit points number rendered 213.5px into a 161px column, 52px past the plate; the canvas export measured real metrics, so only the page overflowed
- **Fix:** one shared measured fit contract (fitCardText + measureOrbitron) for BOTH surfaces; headless on-page SVG audit added (13 violations before, 0 after); 6 vitest fit locks including the exact regression case
- **Files modified:** src/features/export/cardExport.ts, src/features/cards/CardSvg.tsx, scripts/card-render-check/*
- **Verification:** headless audit GREEN; full suite green
- **Committed in:** a8f16e8

**2. [Rule 1 - Bug] Border stroked on the wrong path (round 8)**
- **Found during:** task 4 (owner: border render doesn't match the file)
- **Issue:** both surfaces stroked the CROP path for the border gradient while card.svg (old and new) strokes the PLATE SILHOUETTE — "border in the crop" painted a gradient line across the plate's middle at y≈937
- **Fix:** parser rebuilt on the file's 3-layer semantics (strokePath parsed separately from the clip, semantic KEY groups, role by class+y-order, columns by RATING anchor, no hardcoded y-splits); both surfaces stroke the plate silhouette; permanent file-vs-app render-diff guard added to scripts/card-render-check
- **Verification:** 0 differing pixels on all 4 tiers (on-page), ≤0.07% (canvas, photo-resample AA); border probes re-pointed; 346/346 tests; "ALL CARD GATES PASS"
- **Committed in:** 09383e4

**3. [Rule 1 - Bug] Rating deflation on Destaques (round 8)**

- **Issue:** get_promotion's cmp joined char_function ONLY (0010) while my_card ranks in the class+function cohort (0013); get_promotion also emitted unrounded points

- **Files modified:** supabase/seeds/live/promotion-rating-unification.sql (live-applied), scripts/smoke-promotion.mjs

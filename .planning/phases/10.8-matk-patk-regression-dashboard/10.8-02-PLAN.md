# Phase 10.8 Plan 02 — Angelus / Assumptio Defense Models

**Requirements:** MREG-05 (extends MREG-02/03)
**Depends on:** 10.8-01 (regression dashboard), Phase 9.1 (`rpdef`/`rmdef`), Phase 10.5/10.7 (buff curves)
**Migration:** `0052_regression_defense_fields.sql` (extends the read-only RPC)

## Goal

Extend the regression dashboard to the defense buffs that work like Impositio: **Angelus** (+95% Base PDEF) and **Assumptio** (+95% Equipment PDEF/MDEF). Model `RPDEF × Equip. PDEF%` and `RMDEF × Equip. MDEF%`, fit OLS/Theil–Sen with the same robust curve, and test the buff hypothesis by **dividing the observed defense by 1.95** (the x percent axis is unaffected by the buff).

## Tasks

1. **Migration 0052** — extend `stat_regression_dataset()` with `pdef`, `mdef`, `rpdef`, `rmdef`, `equip_pdef_pct`, `equip_mdef_pct`; coverage `complete_rpdef_pairs` / `complete_rmdef_pairs`; keep `equip_pdef`/`equip_mdef` flat marked unavailable; read-only, staff-only, bookkeeping 0052.
2. **Regression core** — generalize `ModelDefinition` with `debuffKind` (`x_shift` | `y_scale`), `debuffAmount`, `buffLabel`, `xType`/`yType`, model-specific `minR2`; add `rpdef_pct` (y_scale 1.95, minR2 0.25) and `rmdef_pct` (y_scale 1.95, minR2 0.25); generic classification fields (`declaredValue`, `inferredValue`, `observedValue`, `expectedValue`, `residual`, `residualDebuffed`) while keeping the MATK convenience fields.
3. **Dashboard** — 6 charts (MATK×MATK%, PATK×PATK%, ratio, MATK×PATK, RPDEF×PDEF%, RMDEF×MDEF%); model selector; generic classification table/detail card; defense coverage in the data panel; method note (+95% → y/1.95; weaker defense R², exploratory).
4. **Tests** — defense y-scale buff detection (synthetic ×1.95), migration contract, update member fixtures; full suite/tsc/build.
5. **Live verification** — RPC coverage 30/30 for both defense pairs; live robust fit `rpdef` slope 52,75 / intercept 1.945,51 / scale 515,56 / R² 0,365; a synthetic ×1,95 on a real member scores 6,87σ (declared 7,71σ); current max |z| 1,54σ → no forced candidate.

## Success criteria

1. The RPC returns the six defense fields and coverage for both pairs; no source writes (MREG-05).
2. The dashboard exposes RPDEF/RMDEF models and charts; the classification uses y/1.95 for Angelus/Assumptio and x−35 for Impositio.
3. A synthetic ×1,95 defense record is POSSIBLE_BUFF; the current dataset is not forced into a candidate.
4. The MATK/PATK models and reference validation are unchanged.

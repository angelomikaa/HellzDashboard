## What shipped

### Server — `0054_three_state_review_category.sql`
- `submission_anti_cheat` v7 adds `review`:
  ```json
  {
    "category": "consistent | inconclusive | buffed",
    "cohort_available": true,
    "history_available": true,
    "history_sample_size": 6,
    "reasons": ["..."]
  }
  ```
- Category rules:
  - `buffed`: history pattern `impositio`/`defense` or curve `reason='impositio'`.
  - `inconclusive`: any other anomaly (defense sigma, generic curve, history jump, OVR swing) or no reliable reference (no cohort baseline and no validated history).
  - `consistent`: no anomaly + at least one reliable reference.
- `flagged` is now `category <> 'consistent'`; old cached clients still show the warning.
- OCR edits remain evidence only.

### Client
- `api.ts`: `AntiCheatReviewCategory`, `AntiCheatReview`, `flags.review`.

- `AntiCheatPanel`: category border/badge + the server reasons; falls back to the old `flagged` UI on an old server.
- `ValidacoesPage`: the collapsed row chip is now Consistente / Inconclusivo / Buffado.

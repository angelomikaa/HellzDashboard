# Phase 10.9 Plan 01 — SUMMARY

**Status:** complete — client-only reorganization; no migration, no server change.

## What shipped

### Shell — `src/features/rank/RankPage.tsx`
- One tablist with three sibling sections: **Ranking OVR** (default), **Explorador de
  stats**, **Análise estatística**; a single `role="tabpanel"` follows the selection.
- `fetchClasses` + `fetchCatalog` load once and are shared by the first two sections; a
  failure only degrades the filters.
- Identity helpers (`rankCharId`, `hasRankCharId`, `formatRankCharId`,
  `rankIdentityLine`) kept exported for the node-env tests.

### OVR board — `src/features/rank/OvrRankingSection.tsx`
- Function boards (Dano Físico / Dano Mágico / Suporte) from the shared
  `FUNCTION_LABELS` map; merged-class filter (`mergedClassOptions`, Artista shown once).
- Toolbar sort (`OVR` = server order verbatim, `Nome`, `Classe`) and accent-insensitive
  search by name or char ID.
- Summary line: player count, average OVR, `sem dados suficientes` count.
- Removed the redundant Function column; `Ver stats` opens the modal.
- Any board / class / search change keeps the cancelled stale-guard.

### Player detail — `src/features/rank/PlayerStatsModal.tsx`
- `role="dialog"` + `aria-modal`, labelled by the player name, close button focused on
  mount, Tab trapped, Escape and backdrop close, body scroll locked, focus returned to the
  trigger on unmount.
- Header: crest, name, class · function · char ID, OVR.
- Table: all stats grouped Geral → Quasi → Especial with class average, value and the
  tier-coloured points pill (unchanged display contract from 07.2-04).

### Stat explorer — `src/features/rank/StatExplorerSection.tsx` + `StatPicker.tsx`
- Searchable grouped stat picker (label / key / short label), default `rpdef`.
- Filters: merged cohort class, build function, name/ID — all client-side over the
  already-fetched `stat_overview` payload; `Limpar filtros` appears when any is active.
- Summary (members with value, median, max, min) computed from the **filtered** rows;
  `Nσ` and `Fora da curva` badges unchanged.
- Stats picker degrades to `Catálogo indisponível` if the catalog fails.
- "Como ler esta tabela" collapsed by default.

### Analysis — `src/features/rank/AnalysisSection.tsx` + `RegressionDashboard.tsx`
- The regression dashboard (10.8) is now its own section, unmodified in behaviour.
- Methodology, assumptions and the owner reference-pair validation collapsed into one
  `<details>` ("Metodologia, premissas e validação do par de referência").

### Pure helpers — `src/features/rank/rankView.ts`
- `normalizeSearch` (NFD, accent/case-insensitive), `filterRankRows`,
  `summarizeRankRows`, `filterStatRows` (query + merged cohort + function),
  `summarizeStatRows` (median/min/max over non-null values); all non-mutating, no rank math.

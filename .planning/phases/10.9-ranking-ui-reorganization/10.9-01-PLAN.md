# Phase 10.9 Plan 01 — Ranking UI Reorganization

**Requirements:** RUI-01, RUI-02, RUI-03, RUI-04, RUI-05
**Depends on:** Phase 10.6 (`stat_overview` inspector), Phase 10.8 (regression dashboard),
Phase 07.2 (staff Ranking tab), Phase 10.3 (merged class cohorts)
**Migration:** none (client-only)

## Goal

Officers open one Ranking page with three obvious destinations — the OVR boards, a
single-stat explorer, and the statistical analysis — instead of nested modes. The
per-player 59-stat detail opens in a dialog so the board stays scannable.

## Tasks

1. **Section shell** — `RankPage.tsx`
   - One `role="tablist"` with `Ranking OVR`, `Explorador de stats`, `Análise estatística`
     (default `ovr`), one `role="tabpanel"`.
   - Shared `classes` + `stat_catalog` fetch for the first two sections; failures degrade
     filters only.

2. **OVR section** — `OvrRankingSection.tsx`
   - Function boards (Dano Físico / Dano Mágico / Suporte), merged-class filter,
     sort select (OVR / Nome / Classe), name-or-ID search.
   - Summary line (players, average OVR, insufficient-data count).
   - `Ver stats` opens `PlayerStatsModal`; inline expansion removed.
   - No Function column (board already expresses it).

3. **Stat explorer** — `StatExplorerSection.tsx` + `StatPicker.tsx`
   - Searchable grouped stat picker (default `rpdef`), class (cohort group) and function
     filters, name/ID search, ascending/descending toggle, clear-filters action.
   - Summary (members with value, median, max, min) computed from the filtered rows.
   - "Como ler esta tabela" explanation collapsed by default.

4. **Analysis section** — `AnalysisSection.tsx` + `RegressionDashboard.tsx`
   - The regression dashboard keeps its own loading/error handling.
   - Methodology, assumptions and the owner reference-pair validation move into one
     collapsed `<details>`.

5. **Pure helpers + tests** — `rankView.ts`
   - `normalizeSearch`, `filterRankRows`, `summarizeRankRows`, `filterStatRows`,
     `summarizeStatRows` (pure, non-mutating).
   - Tests: OVR/stat filters, summaries, order passthrough; modal and picker render tests;
     shell renders the three sections with OVR selected.

## Success criteria

1. The Ranking page exposes the three sections as siblings, OVR selected by default, with
   no nested tablist.
2. Opening a player shows a dialog with OVR, all stats grouped, class average and points;
   Escape, backdrop and the close buttons dismiss it and focus returns to the trigger.
3. The stat explorer filters by stat, class (Artista merged), function and name/ID without
   a network round trip, and every filter has a visible reset.
4. The analysis section renders the regression dashboard with methodology collapsed.
5. No server change, no new dependency, no key-stat config in any payload; `tsc -b`,
   `oxlint`, the full Vitest suite and `vite build` stay green.

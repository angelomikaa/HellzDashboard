2. **Key-stat remap (DEF-04):** remap every `class_key_stats` row with `stat_key in ('pdef','mdef')` — keys and relevants — to `rpdef`/`rmdef`, preserving `selection_order` and `selected_at`, then delete old rows. Use a CTE so the insert and delete reference the same mapping:
```sql
with remap(old_key, new_key) as (
  values ('pdef','rpdef'), ('mdef','rmdef')
)
insert into class_key_stats (class_name, char_function, stat_key, selection_order, selected_at)
select k.class_name, k.char_function, r.new_key, k.selection_order, k.selected_at
from class_key_stats k
join remap r on r.old_key = k.stat_key
on conflict (class_name, char_function, stat_key) do nothing;

with remap(old_key, new_key) as (
  values ('pdef','rpdef'), ('mdef','rmdef')
)
delete from class_key_stats k
using remap r
where k.stat_key = r.old_key;
```
- FK to `stat_catalog` requires `rpdef`/`rmdef` inserted first (section 1 runs before section 2).
- `selection_order`/`selected_at` preserved per row; OVR nulls for affected classes until new validated submission supplies both raw values (documented operational consequence).

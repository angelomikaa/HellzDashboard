| Boundary | Description |
|----------|-------------|
| anon → request_status | Unauthenticated caller may only learn a handle's request status |
| service role → claim_pin / create_membership_request / identity tables | Only the Edge Functions may write claims and applications |
| member JWT → submission identity | Member may submit identity text but may never set role/active/pin_hash |
| staff JWT → lifecycle/review RPCs | Officers/owners act through gated definer functions only |
| storage.objects → identity proofs | Proof images are staff-only reads; no client writes |

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| screenshot → OCR parser | Untrusted pixels become advisory identity text |
| browser → create_submission | Member-controlled identity fields |
| browser (anon) → request-access | Applicant-controlled identity/stats, no session |
| public catalog → anon | Labels only; no config |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-25 | Spoofing | identity capture | mitigate | Identity is self-declared data, promoted only after staff validation/approval; no access depends on it |
| T-08-26 | Tampering | OCR prefill | mitigate | OCR never overwrites typed fields; class must match the official list; unknown → blank |
| T-08-27 | Tampering | duplicate ID | mitigate | Server unique indexes + `assert_char_id_available`; inline duplicate error |
| T-08-28 | Elevation of Privilege | prospect submit | mitigate | request-access never creates a member; stats land in request tables until staff approval |
| T-08-29 | Information Disclosure | public catalog | mitigate | Anon grant is column-limited to labels/types; key-stat config remains in class_key_stats |
| T-08-30 | Denial of Service | prospect payload | mitigate | Client caps field counts; server validates length/keys; submit disabled while pending |
</threat_model>

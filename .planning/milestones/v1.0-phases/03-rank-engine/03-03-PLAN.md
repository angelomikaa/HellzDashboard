JWT claim contract: `member_role` = 'member'|'officer'|'owner'; identity = `member_id` (uuid).

Rank math (from plan 03-01 — implement IDENTICALLY in SQL):
- points(own, cohort_excluding_self) = ((countBelow + countTies/2) / (n-1)) × 99, n = cohort size + 1, only when n >= 3
- OVR = 51 + mean(6 key-stat points) × (48/99), strict 6, unrounded
- Cohort (D-06): submissions with `status <> 'rejected'` (pending counts today; Phase 6 rejects drop out automatically). Member active-ness is NOT part of the cohort definition (D-06 is status-only, one definition forever).
- Latest value per (member, stat) (D-07): the most recent submission CONTAINING that stat — covers legacy rows missing Special stats.

SECURITY DEFINER precedent (0003 record_pin_failure): `language plpgsql security definer set search_path = public` + internal checks + `comment on function`.

EXECUTE hygiene (WR-02 lesson): Postgres grants function EXECUTE to PUBLIC at creation — every new function needs `revoke execute on function <sig> from public, anon; grant execute on function <sig> to authenticated;`

**3. `set_key_stat(p_class text, p_stat_key text, p_enabled boolean) returns int`** — SECURITY DEFINER, plpgsql, `set search_path = public`:
- Internal gate FIRST: `if (coalesce(auth.jwt()->>'member_role','') not in ('officer','owner')) or not exists (select 1 from members m where m.id::text = auth.jwt()->>'member_id' and m.active) then raise exception 'forbidden'; end if;` (D-03 + D-14)
- Validate: `if not exists (select 1 from classes where class_name = p_class) then raise exception 'unknown_class'; end if;` (stat_key FK violation raises naturally for unknown stats)
- Take the per-class lock to make the limit check race-proof (CR-01 lesson): `perform pg_advisory_xact_lock(hashtext('cks:' || p_class));`
- If `p_enabled`: `if (select count(*) from class_key_stats where class_name = p_class) >= 6 then raise exception 'key_stat_limit'; end if;` then `insert ... on conflict (class_name, stat_key) do nothing;` (D-02: block at 7 — adding a 7th rejected until one is removed)
- If not `p_enabled`: `delete from class_key_stats where class_name = p_class and stat_key = p_stat_key;`
- Return the class's current count: `return (select count(*) from class_key_stats where class_name = p_class);`

**4. `my_report() returns jsonb`** — SECURITY DEFINER, `stable`, `set search_path = public`. This is THE member contract Phase 4 renders. Semantics:
- Identity: `v_member := (auth.jwt()->>'member_id')::uuid`; null → `raise exception 'no_member_claim'`; member row must exist and be `active` else `raise exception 'forbidden'`
- Read caller's `char_class` / `char_function` (may be null — see below)
- **Latest-value CTE** (D-06 + D-07), the trickiest part — use exactly this shape:
```sql
with latest as (
  select distinct on (sub.member_id, ss.stat_key)
         sub.member_id, ss.stat_key, ss.value
  from submission_stats ss
  join submissions sub on sub.id = ss.submission_id
  where sub.status <> 'rejected'
  order by sub.member_id, ss.stat_key, sub.submitted_at desc
)
```
- **Cohort**: latest rows whose member has `char_class = caller's class` AND `char_function = caller's function` (members with null char_class are excluded from every cohort; a null-class CALLER gets own values but null aggregates, null points, data_sufficient=false, ovr insufficient — explicit unclassed handling)
- **Per stat over ALL 57 catalog entries** (left-joined, ordered by group_name then label):
  - `own_value` = caller's latest value or null
  - `class_average` = avg(cohort values), `best` = max(cohort values) — computed whenever the cohort has >= 1 value for the stat, regardless of sufficiency (D-13: values are NOT omitted)
  - `n` = count of cohort values for the stat (caller included)
  - `points` = `case when n >= 3 and own_value is not null then round(((count_below + ties/2.0) / (n-1)) * 99, 2)::numeric ... end` where count_below/ties are computed over cohort values vs own_value using the 03-01 formula (ties includes the caller's own entry: ties = count of cohort values equal to own_value INCLUDING self → use `(ties - 1)::numeric / 2` to match rankMath's others-based formula — verify against the worked examples)
  - `data_sufficient` = (n >= 3)
- **OVR block** (D-09/D-10/D-11/D-12): key stats `ks := select stat_key from class_key_stats where class_name = caller's class`. `ovr.data_sufficient` = (count(ks) = 6) AND caller has non-null own_value for ALL 6 AND each of the 6 has n >= 3. If sufficient: `ovr.value = 51 + avg(6 points) * 48.0/99` (numeric, unrounded). Else `ovr.value = null`.
- **Response shape** (jsonb_build_object):
```json
{ "char_class": text|null, "char_function": text|null,
  "stats": [ { "stat_key", "label", "group_name", "value_type",
               "own_value": numeric|null, "class_average": numeric|null, "best": numeric|null,
               "points": numeric|null, "data_sufficient": boolean } ],  -- all 57, ordered group_name,label
  "ovr": { "value": numeric|null, "data_sufficient": boolean } }
```
- RNK-02 ABSOLUTE RULE: the JSON contains NO key-stat markers — no `key_stats` field, no per-stat `is_key` flag, no key-stat echo anywhere. The RPC reads class_key_stats internally only.
- `comment on function my_report()` documenting the contract + the accepted aggregate leak (avg/best in small guilds — Pitfall 4, conscious tradeoff).

**5. `class_top5(p_class text) returns jsonb`** — SECURITY DEFINER, `stable`. Staff-only (same officer/owner + active internal gate as set_key_stat, else `raise exception 'forbidden'`; D-05 — never member-invocable). Validates class exists (`unknown_class`). Computes each class member's OVR by the SAME semantics as my_report (shared CTE shape; members with insufficient OVR get `ovr: null`), returns up to 5 rows `[ { "display_name", "char_function", "ovr": numeric|null } ]` ordered by `ovr desc nulls last`, then display_name. Design note (discretion): preview reflects the CURRENT config — toggles apply instantly (compute-on-read) and officers sanity-check by viewing the preview after changes; Phase 6 promotion page will reuse this RPC.

(PostgREST calls functions as `authenticated`; membership is enforced INSIDE each function.)
